# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

1. Open the repository's **Security** tab and click **Report a vulnerability** (GitHub private vulnerability reporting). Only the maintainer can see the report.
2. If you cannot use GitHub, use **Report a bug or suggestion** in the app footer and say only that you have a security report and how to reach you. Do not put the details in that form.

Please include the CleanPano version, your Windows version, the steps to reproduce and what an attacker could do.

You should get a first reply within 7 days. Please allow time for a fix to be released before publishing details.

Supported version: the latest release only.

## Scope notes

CleanPano runs as administrator and serves its interface from a local server bound to `127.0.0.1`. Reports about that local server, the installer, the driver and update downloads, or anything that lets another program or website make CleanPano do something the user did not ask for are especially welcome.

# Política de segurança (PT-BR)

## Como reportar uma vulnerabilidade

**Não abra uma issue pública** para problemas de segurança.

1. Abra a aba **Security** do repositório e clique em **Report a vulnerability**. Só o mantenedor vê o relato.
2. Se não puder usar o GitHub, use **Reportar bug ou sugestão** no rodapé do app e diga apenas que tem um relato de segurança e como falar com você. Não coloque os detalhes nesse formulário.

Inclua a versão do CleanPano, a versão do Windows, os passos para reproduzir e o que um invasor conseguiria fazer.

A primeira resposta deve chegar em até 7 dias. Aguarde a correção ser publicada antes de divulgar detalhes.

Versão com suporte: apenas a mais recente.
